# JavaScript Quiz App

An interactive Quiz App built with HTML, CSS and JavaScript.

## Features

- Multiple questions
- Multiple choice answers
- Score tracking
- Correct/wrong answer feedback
- Progress bar
- Final result
- Restart quiz
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript

- Arrays
- Objects
- forEach()
- DOM Manipulation
- Event Listeners

- Conditional Statements
- Template Literals
- createElement()
